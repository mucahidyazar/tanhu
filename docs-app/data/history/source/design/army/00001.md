# Ordu Altyapısı / Army Groundwork

I. Perde'de ordu oynanmaz; I. Perde yalnız `Follower` ve `Squad` çekirdeğini kullanır (`act1.md` §9.7). Çerçeve `act1.md` ve `travel.md` ile aynı: x doğu, z güney, kuzey −z, metre, `heading = atan2(dx,dz)` (π kuzey). Düzen ekseni: `lx` + sol (`Rig`'de `L` tarafı +x), `lz` + ileri. Dünya: `wx = x + lx·cos h + lz·sin h`, `wz = z − lx·sin h + lz·cos h`. Oyun içi metinler TR / EN.

**Alan sahipliği.** Bu belge `UnitRec`, kademeler, birlik eksenleri (`loyalty`, `morale`, `discipline`, `fatigue`), düzen, takipçi ajan, buyruk, çizim ve `army` kayıt bloğunun sahibidir (`progression.md` §11, §16). Beceri tablosu `progression.md` §4.10, erzak verimi `economy.md` §8, yapı hasarı `structures.md` §5, yol bedeli `travel.md` §7, ateş ve yemek `survival.md` sahibinindir.

**Kaynağın söylemedikleri (`kurgu tercihi`, Destan Kitabı'nda işaretlenir).**
- Shiji onluk düzenini Mete'nin icadı demez. 然至冒頓而匈奴最彊大…其世傳國官號乃可得而記云: makam adlarının Mete çağından kayda geçebildiğini yazar. Oyun düzeni Palak'ın Sayım'ından Mete'nin eline geçmiş gibi kurar.
- 24'ün dökümü yoktur: metin altı çift makam (12) sayar, sonra 二十四長 der. Oyun 24 `wanqi` yuvası tutar, dökümü iddia etmez.
- "Tümen" Shiji'de geçmez, sözcük 萬騎'dir. Eski Türkçe *tümen*'in kökeni tartışmalıdır (Toharca ya da Çince kaynaklı önerilir); Teoman adıyla bağı varsayımdır.
- Onbaşı, yüzbaşı, binbaşı bugünkü rütbeleri çağrıştırır; `act1.md` "eski onbaşı" dediği için korunur.
- 10.000, 300.000 ve 400.000 Han kaynağının sayılarıdır; #22 ile gerilimlidir. Oyun gösterimi sayıyı doğrulamaz.

Çekirdek `game.js:586-619` at kinematiği ile aynı karışımı kullanır; fark yuva hızı ileri beslemesi ve durma mandalıdır. Lider `moving` bitince yerinde kalır (`game.js:592`), at ise 12 m/sn'den yavaşlar: mandal bu yüzden vardır.

```js
// Squad: kare başına. Lider durursa düzen dönmez, açılma sabit kalır.
if (L.v > 1) {
  const d = angDiff(L.h - fh);
  if (Math.abs(d) > FLIP_AT && L.v > 2) { fh = L.h; reassignNearest(); }
  else fh += clamp(d, -OMEGA * dt, OMEGA * dt);
}
if (L.v > 4) scale += (1 + STRETCH * clamp((L.v - 6.4) / 5.6) - scale) * Math.min(1, dt * 1.2);

// Follower.follow
slot = worldOf(slotIndex);                                  // giriş satırındaki dönüşüm × scale
vSlot += ((slot - slotPrev) / dt - vSlot) * (1 - Math.exp(-dt / VF_TAU));
goal = pickGoal();                                          // §5.4 merdiveni; mode: slot, crumb, path
ahead = dot(goal - pos, fwd(h));                            // yuva önde mi, arkada mı
if (parked) {
  if ((L.v > 0.6 && ahead > -1) || dist(goal) > OVER_R + 2) parked = false;
} else if (mode === 'slot' && ((L.v < 0.4 && dist(goal) < PARK_IN)
        || (!L.moving && ahead < 0 && dist(goal) < OVER_R))) parked = true;   // yuvayı aştıysa dönme, dur
want = mode === 'slot' ? vSlot + K_SLOT * (goal - pos)
                       : unit(goal - pos) * Math.min(vMax, Math.max(L.v, V_MIN) * 1.2);
want += separation();                                       // SEP_R içi, lider dahil
if (parked) want = 0;
v += (len(want) - v) * Math.min(1, dt * (len(want) > v ? ACCEL : BRAKE));
settle = L.v < 2 && dist(goal) < SETTLE_R && mode === 'slot'; // yana adım, U dönüşü yok
targetH = !parked && !settle && len(want) > 0.3 ? atan2(want) : (L.v > 1 ? L.h : fh);
h += angDiff(targetH - h) * Math.min(1, dt * lerp(9, 3.8, v / 12) * TURN_BOOST);
dir = settle ? unit(want) : 0.55 * fwd(h) + 0.45 * unit(want);
moveWithSlide(pos + dir * v * dt);                          // game.js:602-609 sırası
```

- `customProgramCacheKey` yalnız `key` kullanır (`paint-material.js:138`): `crowd_t1`, `crowd_t2` zorunlu.
- İlk kare derleme takılması ölçüldü: T1 281 ms, T2 137 ms. `compileAsync` yüklemede, `renderer.compile` (`main.js:207`) yetmez.
- `ghost.js:2` çizim sırası: takipçi `renderOrder` 2, kalabalık 3. Aksi halde Mete'nin izi her atlının arkasında yanar. `Folk` `ghost` kapalıyken 0 kalır: elle 2 verilir.
- `Folk.mesh` ve izi tek sabit sınır küresiyle kırpılır (2.2): bütün duruşları içerir, kalabalıkta arkada kalan çizilmez. `Horse` da aynı: `BOUND`.
- Gölge varyantı hook almaz: T1 gölgesi sabit duruş. Uzaktan fark edilmez, kabul.
- Işık sayısı sabit (`code-audit.md`): meşale ve kamp ışığı eklenmez.
- `height()` yakın önbellek dışında `heightRaw`: 1.000 atlı kare başına 0,77 ms (ölçüldü). y 5 Hz, kademeli: 300 atlıda ≈0,05 ms.
