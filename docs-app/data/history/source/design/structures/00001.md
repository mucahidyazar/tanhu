## 1. Gerçek kurulum sırası ve sözcükler

2–3 kişi bir boz yurdu gerçekte 60–90 dakikada kurar. Oyun emeği K21 ile sabitler: yurt bir işçinin bir iş günüdür (1.440 iş dakikası, tek işçiyle 60 gerçek dakika); ekip büyüdükçe süre azalan verimle kısalır (§2.4). Sıra korunur.

| Sözcük | Oyun içi TR / EN | Gerçek işlevi |
|---|---|---|
| bosağa | Bosağa / Door Frame | İlk dikilen parça: dikmeler, lento, eşik. Kerege buna bağlanır, yönü de belirler |
| kerege, kanat | Kerege / Lattice Walls, Kanat / Wing | Makaslı çıta duvar. Her kanat katlı gelir, açılır, komşusuna bağlanır |
| kerege bağı | Kerege Bağı / Tension Band | Kerege başlarını çeviren dokuma kuşak. Çatının itişini bu tutar |
| tündük | Tündük / Crown | Taç halkası, duman deliği |
| bakan | Bakan / Raising Pole | Tündüğü iterek kaldıran çatal sırık; iş bitince alınır |
| uuk (uyk) | Uuk / Roof Poles | Tündükle kerege başı arasına birer birer takılan sırıklar |
| iç örtü, çiy | İç Örtü / Inner Liner, Çiy / Reed Screen | Keregenin içindeki dokuma, dışındaki kamış hasır |
| tuurduk | Tuurduk / Felt Walls | Duvarı saran keçe paneller |
| üzük | Üzük / Felt Roof | Saçaktan tepeye çekilen çatı keçeleri ve tündük örtüsü |
| kolan | Kolan / Girth Ropes | Keçeyi tutan çember ve radyal halatlar |
| kapı keçesi | Kapı Keçesi / Door Curtain | Sarılı kapak |
| şırdak | Şırdak / Floor Felts | Taban keçesi |
| ocak, köz | Ocak / Hearth, Köz / Ember | Son iş: başka ocaktan getirilen közle ilk ateş, ilk duman |

**Tarih notu.** Shiji Hunların evini 穹廬 (kubbeli keçe çadır) diye anar; makaslı kerege biçimi kesin olarak daha geç dönemden belgelidir, sözcükler bugünkü Kırgız-Kazak söz varlığıdır. Mevcut yurt modeli ve iç duvar dokusu bu biçime dayandığı için korunur; Destan Kitabı'nda `tasarım tercihi` diye not düşülür, Kurgu listesine girmez.

## 2. Genel model

### 2.1 Kavramlar

| Kavram | Kimlik | Anlam |
|---|---|---|
| Yapı | `StagedStructure` | Dünyadaki tek bina, tür tanımı `STRUCTURE_DEFS[kind]` |

| Emek | `work` | Adımın ekip emeği (iş dakikası); `solo` tek el çarpanı (tek el emeği `work × solo`), el sınırı `min`–`max` (§2.4) |

### 2.2 Veri biçimi

```js
// world/structure-defs.js
STRUCTURE_DEFS.yurt = {
  stages: 8,
  presets: { hero: {...}, winter: {...}, closed: {...} },   // §3.5
  craft: 'home', crewMax: 8,                                         // §2.4
  steps: [
    { id: 'y_kerege', stage: 2, name: { tr: 'Kerege', en: 'Lattice Walls' }, work: 146, min: 1, max: 8,   // tek el yöntemi yalnız y_tunduk'ta: solo: 1.6, min: 2
      cost: { 'tag:wood': 8, rope: 2 }, mat: 'lattice', hp: 45,
      parts: { kerege_set: 1 }, rawWork: 720, rawRole: 'cr_carpenter',   // K24: parça gelirse cost karşılanır; ham gelirse adıma rawWork İD eklenir (§2.4)
      units: [ { id: 'k0', hp: 7.5, group: 4, arc: [0.1385, 1.1395] }, /* k1..k5 */ ],
      order: ['k0', 'k5', 'k1', 'k4', 'k2', 'k3'],
      nav: 'wings', jobs: 'j_kerege', help: 'help_hold' },
    // ...
  ],
};

// world/structure.js
class StagedStructure {
  constructor(def, place, world, { mode: 'timed' | 'script', preset, startFull })   // K20: 'slice' kalktı; Kışlak da dünya saatiyle
  stage; step; stepT; wm;             // aşama, adım dizini, adım içi 0..1, işlenen emek (iş dakikası)
  // emek: sürücü state.advance(wm) çağırır (StructureState, architecture.md §3.11); wm = oran × oyun dakikası, atlamada toplu (§2.4, §2.5)
  deliver(item, n, who);              // malzeme; who 'player' | 'npc', contrib sayılır; bohça (yurt_kit, tent_kit) açılır
  credit(wm);                         // senaryo armağanı, çarpansız
  dismantle();                        // söküm: tersten, emeğin 0,35'i (§2.4)
  hit(atk, point, dir);               // §5.2
  ignite(point, { power, torch });    // §6
  setStage(n, { cause, stagger });    // senaryolu düşüş
  tear(panel, { len, rot });          // senaryolu yırtık
  repairStep(wm, who);                // §7, iş dakikası
  groundAt(x, z);                     // §11.3, Room.floorAt'ı sarar
  navShapes();                        // §12.2
  toJSON(); fromJSON(o);              // §11.8
  unit(id); ensureStage(n); panelFacing(dir); cutRoof(); beginHeave();   // senaryo yardımcıları (§14)
}
// Olaylar: 'stage', 'unitFall', 'ignite', 'out', 'stepDone', 'done', 'breach'
```

**Parça ve ham biçim (K24, `economy.md` §6.3).** `cost` a1 ham biçimidir ve değişmez. `parts` aynı adımın II. Perde ve sonrası bileşen biçimidir: teslim edilen parça `cost`'u bütünüyle karşılar. Şantiyeye ham mal gelirse adımın emeğine `rawWork` İD eklenir (bileşen tarifinin İS'i × 60) ve `rawRole` varsa ekipte o rolün ustası bulunmalıdır; yoksa ham pay işlemez, adım `master` nedeniyle bekler (usta tarifinin ustasız yolu yoktur, `economy.md` §6.7). I. Perde ve ana kampın şantiyeleri (`camp3`, Kışlak Yeni Yurdu, onarımlar, senaryo şantiyeleri) `spec.labour.rawWork: false` taşır: malzeme yontulmuş gelir, `rawWork` eklenmez. Bohça (`yurt_kit`, `tent_kit`) teslimde açılır. Etiket çözümü `matches(id, ref)` iledir (`architecture.md` §3.13), ad öneki değil.

`StructureManager` (`world.structures`) listeyi tutar, kareye bir kez `update(dt, t)` çalıştırır, `setMode('menu' | 'play')` ile görünümü değiştirir (§8.5).

### 2.4 Emek yasası / Labour Law (K21)

Kullanıcı: «1 yurt 1 kişi ile 1 günde kurulabilsin, kişi arttıkça süre azalsın» (`decisions.md` K21). Sayıların makine okunur kopyası `d2/labour-model.json` v2'dir (2026-11-03, bu bölümle aynı sayılar); kesişen sayılar `d2/core.md` §2.

**Birimler.**

| Ölçü | Değer |
|---|---|
| İD, iş dakikası | Bir işçinin bir oyun dakikası emeği; tek işçiyle 1 İD = 2,5 gerçek sn (K20: 1 oyun günü 60 gerçek dk) |
| İS, iş saati | 60 İD |
| İG, iş günü | 1.440 İD = 24 İS = tek işçiyle 60 gerçek dk |

Emek dünya saatiyle akar (`WorldClock.abs`): saat durunca (menü, duraklatma, harita, diyalog, Bekle tekeri) emek de durur; saat atlayınca (uyku, Bekle, çalışma, yolculuk) emek `clock:skip`'te toplu işlenir (§2.5). Bütün yapılar, onarım, taşıma, söküm ve zanaat (`economy.md` §6.7) aynı birimle ve tek emek havuzundan ödenir.

**Ekip verimi.**

```
eff(W) = min(W, 10 · (1 − 0,9^W))      // W ≤ 1'de doğrusal, W ≥ 1'de K21 dizisi
W      = adımın el sınırına (max) dek en ağır üyelerin ağırlık toplamı;  eller = baş sayısı
oran   = eff(W) × K_usta × K_beceri × K_gece × K_hava × K_tok × hız / solo     // İD / oyun dk
solo   = eller < adım.min ? adım.solo : 1     // yurtta yalnız y_tunduk: bakanla ×1,6
```

| W | 0,5 | 0,75 | 1 | 1,5 | 2 | 2,5 | 2,75 | 3 | 3,25 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| `eff` | 0,50 | 0,75 | 1 | 1,46 | 1,90 | 2,32 | 2,52 | 2,71 | 2,90 | 3,44 | 4,10 | 4,69 | 5,22 | 5,70 |

Her yeni el bir öncekinden biraz az katar: aynı ipi, kanadı, yolu paylaşırlar. `eff` toplam ağırlığa bakar, sıra bağımsızdır; el sınırı aşılırsa en ağır üyeler çalışır, kalanlar taşır ya da sonraki adımın yığınını hazırlar. Yapı başına tavan tanımın `crewMax`'ıdır (yurt 8, otağ 12; §4.6). Tek yapıyı çabuk bitirmek ile iki şantiyede toplam işi büyütmek arasındaki seçim oyuncunundur.

**Zanaat** (`def.craft`): `home` (Ev / Household: yurt, otağ, çadır, çit, ağıl, keçe avlusu, ordugâh yapıları; her yetişkin ustadır), `wood` (Ağaç / Woodwork: ahır, sundurma, ambar, kule, köprü, araba, atölye), `earth` (Toprak / Earthwork: kuyu, sur ve hendek, yarı gömük ev, ocak ve fırın, tarla). Ekonominin zanaatçı rolleri bunlara eşlenir (`economy.md` §6.8): `cr_carpenter`, `cr_cartwright`, `cr_bowyer` → `wood`; `cr_smith`, `cr_earth` → `earth`; ötekiler `home`. **Önder kuralı:** ekipte ağırlığı ≥0,75 ya da usta sayılan biri yoksa iş ilerlemez (yırtık dikmek hariç). **Usta kuralı:** yapının zanaatından usta yoksa oran ×0,7: «Usta yok: iş yavaş» / «No master: the work is slow».

**Mete** ekipte 1 ağırlıktır, `home` ustası sayılır. `quick_raise`: Mete ekipteyken o şantiyenin oranı ×1/0,7 (≈×1,43), Mete'nin buyurduğu şantiyeye yerleşimin boştaki elinden biri kendiliğinden katılır; `repair`: Mete'nin çalıştığı onarımda emek ×0,5, malzeme ¼; `carry_pack`: taşıma seferinde yük tavanı +8; `wagon_ring` savaş düzenidir, emek yasası dışında kalır (`progression.md` §4.5). Tek başına Mete bir yurdu 60 dk'da, `quick_raise` ile 42,0 dk'da kurar; ilk onlukla (8 el) 11,2 dk, `quick_raise` varsa 7,8 dk (beceri seviye 7 ve «Önce bir yurdu bitir» ister: II. Perde'nin ilk yurdu becerisizdir). **Esir emeği yoktur:** işçi havuzu hane, er ve gönüllü firaridir (K23).

### 2.5 Şantiye / Building Site (K21, K23)

**Kavram.** Şantiye (`ConstructionSite`) bir `StagedStructure`'ın yerleşimden bitişe ve sökümüne dek bütün yaşamıdır: yer, yığın, ekip, emirler, bekleme nedeni, katkı. Her `STRUCTURE_DEFS` türüyle çalışır. camp3 onun elle döşenmiş bir örneğidir (§11), Kışlak Yeni Yurdu senaryolu bir örneği (§14, `act1.md` §9.3), II. Perde'den yerleşim ve ordugâh yapıları oyuncunun açtığı örneklerdir (K23, §4.6, `settlement.md` §7). I. Perde altyapıyı ve geliştirici kum havuzunu kurar (`?state=play&sandbox=site`; yerleşim kipi `&hold=1`); hikâye açılışı II. Perde'dedir.

**Yerleşim.** Yapı listesinden tür seçilir; ayak dibinde iz önizlemesi (`Game.marker` gölgelendiricisi, yeni program yok), `plan` bağlamında Q / E 15° döndürür (Shift ile 5°; `ui_prev`, `ui_next`), tekerlek yakınlaşır; ayrı `rotate` eylemi yoktur (`architecture.md` §3.2; `keymap.js` 8.9'undur); kapı varsayılanı yerleşimin ocağına bakar. Geçerli yer: iz `def.bounds` ile; yürüme ızgarasında kapalı hücre (`blocked`, `sb`) yok; eğim normal.y ≥0,9 (yurtta ped, `site-pad.js` genelleşir); su ve buz yok; başka yapının duvarına ≥4 m; yollara ≥3 m; senaryo yasak alanı yok. İzdeki ağaç ve iri kaya yerleşimi engeller (önce kesilir, kırılır); dal, ot, tezek düğümleri `y_site`'ta silinir (`perm` biti). Geçersizse halka kızıl, en çok üç neden yazılır: «Yer düz değil» / «The ground is not level», «Ağaç var» / «A tree stands here», «Başka yapıya çok yakın» / «Too close to another building». Yer işaretlenince aşama 0 öncesi şantiye doğar: kazık ve ip izi, boş yığın alanı. Yerleşimde Plan Kipi bu yolun arayüzüdür (`settlement.md` §14.1).

**Yığın ve teslim.** Yığın / Stock şantiyenin kapı yanındaki dikdörtgenidir, bir `Container`'dır (`inventory.site(id)`, `economy.md` §4.5): kapasite türün malzeme yükünün 1,25 katı. Oyuncu yığında `E` 1 sn: heybedeki uyan malzeme girer, `contrib.player` sayılır; yığın dikdörtgenine bırakılan yer yığını teslim sayılır; araba yükü varışta kendiliğinden boşalır; bohça açılır. Adım başlarken o adımın `cost`'u (ya da `parts`'ı) yığından adıma geçer; eksikse adım başlamaz: «Malzeme bekliyor: {list}» / «Waiting for materials: {list}».

**Ekip atama.** Havuz yerleşim halkı (hane kaydı: yetişkin, çırak; çocuk atanmaz), ordugâhta birliğin eli (`strength − wounded`, `cmd_detail` İş Kolu), I. Perde'de senaryo kişileri. Bir kişi aynı anda tek şantiyededir; şantiyede çalışan başka iş üretmez. Şantiyede `E` «Ekip / Crew» ya da Yerleşim Defteri'nin yapı sayfası: + / − ile el, usta kendiliğinden seçilir; öncelik 0–3; «Boştaki eller yapıya / Idle hands to building» yerleşim ayarı. Mete «Çalış / Work» ile 1 ağırlıkla girer, Çocuk «Ustalara Katıl / Join the Builders» ile yarım el; hareket girdisi çıkarır: «Ekipten ayrıldın» / «You left the crew».

**İlerleme.** Görünen ve uzak bütün şantiyeler kare başına `dİD = dOyunDk × oran` işler; oran ekip, gece, hava ya da yığın değişince yeniden hesaplanır (≤4 Hz). Adım bitince `structure:step_done`, yapı bitince `structure:done` ve `site:done`. Ustanın görünümü emek çizelgesini süsler, takılan işçi emeği kilitlemez (§10.2). Kadraj dışındaki şantiyede işçi çizilmez, emek işler; 40 m içinde en çok 8 tam `Folk`, 40–120 m kukla, ötesi yok.

### 5.2 Vuruş çözümü

```js
hit(atk, point, dir) {                           // atk: { type, sdmg, statMul, structMods, tag }
  const L = this.toLocal(point);                 // lx, y, lz, a = atan2(lx, lz)
  const unit = this.resolveUnit(L, dir, atk);    // aşağıdaki tablo
  let d = hitStructure(atk, unit);
  if (unit.stage < this.stage) d = chip(unit, d); // §5.4
  this.applyDamage(unit, d);                     // taşma: aynı havuzda en yakın canlı birim, sonra alt havuz
  fx.hit(atk, unit.mat, point, dir);             // §5.5
  if (atk.type === 'slash') this.stampTear(L, atk);
  if (atk.tag === 'arrow') fx.stickArrow(point, dir, unit);
  if (atk.type === 'fire') this.ignite(point, atk);
  this.shake(dir, atk);
}
```

### 6.2 Yayılma

- **Sıçrama:** 4 sn'de bir, yanan yapıdan `R = 10 + rüzgâr` m içindeki her yapıya: `p = P0[dış katman] × (1 − d/R) × (1 + 1,5 × max(0, rüzgâr·yön)) × ıslak`.
- **`d` izler arası boşluktur (Faz 7, `L` kararı):** `d = max(0, merkezler arası − r₁ − r₂)`, `r` yapının iz yarıçapı (`bounds().r`). Çit ve ağıl gibi çizgi izde merkezin yerini ayaktaki en yakın parça alır, `r` 0'dır (iki çizgi yapı arasında ayaktaki parçaların en kısa uzaklığı); ayakta parça yoksa sıçrama yoktur. Rüzgâr payının yönü merkezden merkezedir. Böylece kampta A ile üçüncü yurt (duvarlar arası 4,74 m) birbirini tutuşturabilir; merkezden ölçülen eski kural kamptaki hiçbir çiftte (en yakını 13,4 m) sıçrama vermiyordu.
- `P0`: `felt` 0,08, `bands` 0,04, `reed` 0,3, içi ot 0,5, `wood` 0,04, `lattice` 0,04.
- Rüzgâr hızı ve yönü havadan gelir (`weather.md` §8.6): `StructureManager.wind = clamp(rüzgâr + 0,5 × bora; 0; 24)`, `windDir` havanın akış yönü. Havasız dünyada (sınama, menü) 3 m/sn ve `U.uWindDir` yönü kalır. Kara Boran 8 m/sn (`act1.md` §10 ile aynı sayı); I. Perde baskın kilidi 3 m/sn, kuzeydoğudan.
- `ıslak` (`spreadEntry.wet`, hava her kare yazar): keçe ve saz `min(1 − 0,8 × keçeIslaklığı, karÇarpanı)`; ahşap `1 − 0,4 × keçeIslaklığı`; taş ve metal 1. `karÇarpanı`: Kışlak'ta taze kar (son yağışın örtüsü >0,5) 0,2, aksi 0,5 (eski sayılar korunur); karın tutmadığı iklimde 1. `keçeIslaklığı` 0..1 yağmurla ıslanır, güneş ve rüzgârla kurur (`weather.md` §5.9).
- Çim, ağaç ve yer yanmaz, kamp ateşi yapıya sıçramaz (`survival.md` ateşi yapıya ≥6 m kurulur). Sıçrama yalnız yapılar arasıdır: bütçe ve okunurluk.
- Aynı anda ≤3 yapı tam alevli (`fxFlames` 24, birim başına ≤3, en yakınlar). Gerisi hesapta yanar, 1 duman sütunu gösterir.

### 9.3 GLSL (derlendi, r187'de koştu)

```glsl
// STAGE_PARS (parts, frame)
attribute vec4 aStg;
attribute vec3 aPiv;
uniform vec4 uGK[16];
uniform vec4 uGF[16];
uniform vec4 uHoist;
uniform vec4 uShake;
varying float vStgD;

// STAGE_VERT (begin_vertex sonrası)
vStgD = 1.0;
{
  int g = int( aStg.x * 255.0 + 0.5 );
  float kG = uGK[ g >> 2 ][ g & 3 ];
  float tF = uGF[ g >> 2 ][ g & 3 ];
  if ( kG < 1.0 || tF > 0.0 || uHoist.x > 0.0 ) {
    int md = int( aStg.w * 255.0 + 0.5 );
    float t = clamp( ( kG - aStg.y * 0.88 ) / 0.12, 0.0, 1.0 );
    float e = t * t * ( 3.0 - 2.0 * t );
    vec3 rel = transformed - aPiv;
    if ( md == 0 ) {
      rel.y *= e;
    } else if ( md == 1 ) {
      rel *= e;
    } else if ( md == 2 ) {
      float a0 = atan( aPiv.x, aPiv.z );
      float da = atan( transformed.x, transformed.z ) - a0;
      if ( da < 0.0 ) da += 6.28318;
      float na = a0 + da * e;
      float R = length( transformed.xz );
      rel = vec3( sin( na ) * R, transformed.y, cos( na ) * R ) - aPiv;
    } else if ( md == 3 ) {
      rel.y += rel.x * uHoist.y - uHoist.x;
    } else if ( md == 4 ) {
      float sw = ( 1.0 - e ) * 1.1;
      float c = cos( sw ), s = sin( sw );
      vec2 rd = normalize( aPiv.xz + vec2( 1e-4 ) );
      float h = dot( rel.xz, rd );
      float nh = h * c - rel.y * s;
      rel.y = h * s + rel.y * c;
      rel.xz += rd * ( nh - h );
    } else if ( md == 5 ) {
      vStgD = kG - aStg.y;
    } else if ( md == 6 ) {
      rel.y *= 1.0 - uHoist.x / 8.0;
    }
    if ( e <= 0.0 && md != 5 ) rel = vec3( 0.0 );   // Sıfır alan: parça maliyeti yok
    transformed = aPiv + rel;
    if ( tF > 0.0 ) {
      float an = aStg.z * 6.28318;
      vec3 ax = normalize( vec3( cos( an ), 0.35, sin( an ) ) );
      float wn = tF * ( 1.2 + aStg.z * 3.0 );
      float ca = cos( wn ), sa = sin( wn );
      vec3 q = transformed - aPiv;
      q = q * ca + cross( ax, q ) * sa + ax * dot( ax, q ) * ( 1.0 - ca );
      transformed = aPiv + q;
      transformed.y -= 4.9 * tF * tF;
      transformed.y = max( transformed.y, 0.03 + aStg.z * 0.12 );
    }
  }
}

// SHAKE_VERT (bütün yapı ağları)
if ( uShake.z > 0.0 ) {
  float sk = uShake.z * exp( -uShake.w * 7.0 ) * sin( uShake.w * 26.0 );
  transformed.xz += uShake.xy * sk * smoothstep( 0.0, 8.0, transformed.y );
}

// PARTS_COLOR (color hook, Room CUT_COLOR'dan önce)
if ( vStgD < 0.0 ) discard;
if ( uChar > 0.0 ) diffuseColor.rgb *= mix( 1.0, 0.16, smoothstep( 0.15, 0.85, uChar + ( gBrush.r - 0.5 ) * 0.5 ) );

// TEX_VERT (kabuk, iç duvar; aStg yok)
vSP = position; vSUv = uv;   // + SHAKE_VERT

// TEX_COLOR
if ( uStageOn.x > 0.5 ) {
  int pn = int( fract( atan( vSP.x, vSP.z ) / 6.28318 + 1.0 ) * 4.0 );
  bool roof = vSP.y > 4.1;
  int idx = roof ? pn + 4 : pn;
  float ff = roof ? ( vSP.y - 4.1 ) / 4.3 : ( 4.1 - vSP.y ) / 4.1;
  if ( ff + ( gBrush.r - 0.5 ) * 0.18 > uFelt[ idx >> 2 ][ idx & 3 ] * 1.2 - 0.1 ) discard;
}
if ( uStageOn.y > 0.5 ) {
  vec4 dmg = texture2D( uDmg, vSUv );
  float hole = dmg.r + ( gBrush.g - 0.5 ) * 0.3;
  if ( hole > 0.5 ) discard;
  diffuseColor.rgb = mix( diffuseColor.rgb, vec3( 0.2, 0.13, 0.08 ), smoothstep( 0.2, 0.5, hole ) );
  diffuseColor.rgb *= mix( vec3( 1.0 ), vec3( 0.1, 0.085, 0.08 ), dmg.g );
  diffuseColor.rgb *= mix( vec3( 1.0 ), vec3( 0.86, 0.8, 0.7 ), dmg.a );
}

// TEX_EMISSIVE (STOVE_EMISSIVE sonrası)
if ( uStageOn.y > 0.5 && uEmber > 0.0 ) {
  totalEmissiveRadiance += vec3( 2.0, 0.55, 0.08 ) * texture2D( uDmg, vSUv ).b * uEmber * ( 0.7 + 0.3 * sin( uTime * 7.0 + vSP.x * 3.0 ) );
}

// DEPTH_FRAG (MeshDepthMaterial, clipping_planes_fragment sonrası; fırçasız)
if ( uStageOn.x > 0.5 ) {
  int pn = int( fract( atan( vSP.x, vSP.z ) / 6.28318 + 1.0 ) * 4.0 );
  bool roof = vSP.y > 4.1;
  int idx = roof ? pn + 4 : pn;
  float ff = roof ? ( vSP.y - 4.1 ) / 4.3 : ( 4.1 - vSP.y ) / 4.1;
  if ( ff > uFelt[ idx >> 2 ][ idx & 3 ] * 1.2 - 0.1 ) discard;
}
if ( uStageOn.y > 0.5 && texture2D( uDmg, vSUv ).r > 0.5 ) discard;
```

### 10.3 İş oranı

`oran = eff(W) × K_usta × K_beceri × K_gece × K_hava × K_tok × hız / solo`, iş dakikası / oyun dakikası (§2.4). `eff(W) = min(W, 10 · (1 − 0,9^W))`; W, adımın el sınırına (§3.1 «El») dek en ağır üyelerin ağırlığı: usta ve el 1, çırak 0,75, Çocuk 0,5. `solo` yurtta yalnız `y_tunduk`'tadır: tek baş kalınca bakan yöntemi (171 / 107). `REPAIR`'daki usta o adımda sayılmaz. Çocuk adımın fiilini yaptıkça 0,5 ağırlık ve bir baştır (§11.6). `quick_raise`: Mete ekipteyken ×1/0,7, Mete'nin buyurduğu şantiyeye +1 el. Gece ışıkta ×1, ay ışığında ×0,7, karanlıkta ×0,4; camp3'ün iki meşale direği batıştan sonra yanar. Su çarpanı kalkar: su zemin adımının ayak işidir (§11.6). Kışlak'ta dilim kipi kalkar: `timed` kip, dünya saati; Yeni Yurt ekibi `act1.md` §5 saat programındadır (Nanay 10:30–19:30, iki el 07:00–23:00), aşamayı malzeme ve hikâye kapıları belirler (§14, `act1.md` §9.3).

### 12.1 `nav.js` değişikliği

```js
// constructor
this.sb = new Uint8Array(n);    // yapı engeli, şişirilmiş
this.st = new Float32Array(n);  // yapı yüksekliği, şişirilmemiş, işaretli
this.epoch = 0;

closed(k) { return this.blocked[k] === 1 || this.dyn[k] > 0 || this.sb[k] === 1; }

rawTop(x, z) {
  const i = this.toI(x), j = this.toJ(z);
  if (!this.inside(i, j)) return Infinity;
  const k = this.idx(i, j), a = this.top[k], b = this.st[k];
  return Math.abs(b) > Math.abs(a) ? b : a;

clearLayer(x0, z0, x1, z1) { /* kutudaki sb ve st sıfırlanır */ }
```

### 12.2 Şekiller

```js
// core/shapes.js: yerel +z'den, sin/cos yönünde a0..a1 yay
export function arc(cx, cz, rIn, rOut, rot, a0, a1, top = Infinity) {
  const c = Math.cos(rot), s = Math.sin(rot), mid = (rIn + rOut) / 2, th = (rOut - rIn) / 2;
  const am = (a0 + a1) / 2, ah = (a1 - a0) / 2;
  return { cx, cz, R: rOut, top, d: (x, z) => {
    const dx = x - cx, dz = z - cz, lx = dx * c - dz * s, lz = dx * s + dz * c;
    let da = Math.atan2(lx, lz) - am;
    da = Math.atan2(Math.sin(da), Math.cos(da));
    if (Math.abs(da) > ah) {
      const e = am + Math.sign(da) * ah;
      return Math.hypot(lx - Math.sin(e) * mid, lz - Math.cos(e) * mid) - th;
    }
    return Math.abs(Math.hypot(lx, lz) - mid) - th;
  } };
}
```
